# mcp-gdrive — форк MCP-сервера Google Drive / Sheets

Зарегистрирован в Claude Code как `gdrive` (`node …/mcp-gdrive/dist/index.js`). Push — в remote
`fork` (`dmitry-simple-it/mcp-gdrive`), рабочая ветка `fix/user-entered-value-input`.

## Git: коммит и push без спроса (правило владельца 15.10.2026)

Коммитить и пушить в `fork` можно сразу, без отдельного вопроса, когда это нужно (готовая
проверенная правка, перед перезапуском сервера и т.п.). Это перекрывает общее «коммит только
по слову». Остаётся в силе:
- коммит — после `npm run build` без ошибок и проверки правки;
- в сообщении коммита — что изменилось; в отчёте пользователю — SHA;
- без force-push и переписывания истории; в upstream (`isaacphi/mcp-gdrive`) — не пушить и PR не
  открывать без просьбы.

## Сборка

`npm run build` → `dist/`. `/dist` в `.gitignore`, но часть файлов там отслеживается: новые
собранные файлы в коммит не попадают, на свежем клоне нужен `npm run build`. Новые инструменты
видны в сессиях Claude Code только после переподключения сервера (`/mcp`) или новой сессии.
